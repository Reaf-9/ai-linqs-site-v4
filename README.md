## 文言と文字組み

日本語コピーは `_v3.0-index.html` を参照し、SPEC-v3.1.md と SPEC-v3.2.md に新規指定された文章のみを追加・変更しています。トップの事例要約は既存成果文からの抜粋です。声・数値・実績は創作していません。会社情報・出典・料金の `[要確認]` 等の表記とHTMLコメントは保持しています。

ヒーローの見出しは3行、想いの見出しは2行、3本柱は各見出し2行・本文3行の明示改行です。元の本文を削ったり、行数を合わせるために宣伝文を追加したりしていません。お悩み・理由・サービス・事例要約・LINE特典・無料相談カードにも意味の切れ目で明示改行を入れています。

見出しには `text-wrap: balance`、`word-break: auto-phrase`、`line-break: strict`、本文には `text-wrap: pretty` と `word-break: auto-phrase` を指定。短い語尾や句は `.phrase` の inline-block で保護しています。本文は16px以上・行間1.8・最大38em、注記のみ13pxです。3列のカードは等幅のCSS Grid、`align-items: stretch`。幅1199px以下では1列にして、本文を小さくせず読みやすさを保ちます。指定された固定行数の見出しは `clamp()` で調整しています。

ヒーローは既存の `hero.mp4` と `hero-poster.jpg` を使用。既存の寸法・cover・左寄せを維持し、動画上の文字幅は40%以内です。幅1199px以下では動画と文字を上下に分離します。トップの「ご契約までの流れ」は写真・丸数字・見出し・本文の縦型4工程で、スマートフォンでは写真が上です。サービスページの既存工程は従来の配置を維持しています。

## 機能

- 共通ナビ：トップ／会社概要／サービス／実績／お問い合わせ。該当ページは青い塗りと `aria-current="page"`。
- 全ページに `noindex,nofollow` と3種類のfavicon。
- `[data-line-cta]` は `https://lin.ee/XFEkgJS` に差し替え、新しいタブで開きます。URLの設定は `js/main.js` 冒頭の `LINE_URL`。
- JavaScript無効時もページ間移動・サービス詳細・FAQ・プライバシーポリシーは利用できます。LINEボタンはお問い合わせページへ移動し、QRを利用できます。モバイルにもnoscriptナビがあります。
- 幅767px以下ではヒーロー／ページ冒頭を通過すると固定LINE CTAを表示し、問い合わせ・LINE登録・フッターが見えている間とメニュー表示中は隠します。
- メニューはEscape・外側クリック・リンク選択で閉じます。
- 通常のフェードインは16px・0.6秒。新しいタイミング挿絵は24px・0.8秒、その開始から0.4秒後にHTMLの「！」が0.4秒でscale(0.6)→1となります。各動作は一度だけです。
- `prefers-reduced-motion` では動きを無効にし、動画は `pause()` とメディアのリセットによりポスターのみ表示。設定の途中変更にも追従します。JSやIntersectionObserverが使えない場合も挿絵とマークは表示されます。
- 「テスト版 v3」はローカル／github.ioのPC表示のみ。幅767px以下では非表示。
- トップのLINE枠内QRはPCのみ。お問い合わせページのQRは全幅で表示します。

## CSSで使用する色・角丸

- 色：`#FFFFFF`、`#EDF1F9`、`#327AFA`、`#0F0F11`、`#616267`、`#9798A1` の6色のみ。
- 使用角丸：`12px`、`16px`、`24px`、`32px`、`9999px`。許可値4pxは今回は未使用。
- 影・グラデーション・RGBA色は使っていません。ヒーローには角丸を指定していません。
- レイアウト余白は8pxの倍数。写真そのものの色はCSS配色制限の対象外です。
